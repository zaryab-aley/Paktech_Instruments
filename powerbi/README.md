# Power BI report

Open Paktech_Dashboard.pbix in Power BI Desktop. This is the supplied report, copied without rewriting its binary contents. Configure credentials locally; point Power Query at your server if using a different Synapse workspace. Refresh only after successful full Gold publication and save.

The report uses Import mode. There is no Power BI Service publication or automatic refresh in this project. The four pages retain their supplied names Page 1–4. Dashboard images are optional follow-up evidence, not included/generated screenshots.

Extracted text companions: measures.dax, calculated_columns.json, relationships.json, power_query.json, model_row_counts.json. They help reviewers inspect implementation without opening the binary and do not replace the PBIX model. Some Power Query conversions/deduplication remain part of the report.
